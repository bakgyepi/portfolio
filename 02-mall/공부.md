## LifeCycle : 컴포넌트도 사람처럼 태어나고 죽는다.
컴포넌트의 마운트-업데이트-언마운트 ---> 인생 주기마다 간섭(코드실행)을 할 수 있다. 
useEffect 동작원리 : 실행 시점이 다르다. html 렌더링 이후에 동작
useEffect 자주사용하는 : 시간이 오래 걸리는 작업을 감싸기, 서버에서 데이터, 타이머

Effect는 왜 이펙트임 ? -> 사이드이펙트에서 따옴


useEffect(()=>{
    마운트될 때
})

let [count, setCount] = useState(0)
useEffect(()=>{
    변경(update)될 때
},[다른 state이름])

useEffect는 함수임. state가 변해서 리랜더링 된 후, 딱 한 번만 실행해주는 코드.
